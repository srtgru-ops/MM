نظام إدارة مركز محترف - نسخة أولية

1) افتح index.html لتجربة الواجهة.
2) لكل Google Sheet افتح Extensions > Apps Script والصق google-apps-script.gs.
3) انشره كـ Web App وخذ الرابط.
4) افتح index.html وابحث عن const FORMS ثم ضع رابط كل Web App في api:''.
5) غيّر أسماء form2/form3/form4 إلى أسماء النماذج الفعلية.

ملاحظة أمنية: لا تجعل Web App عامًا إذا كانت البيانات شخصية إلا إذا كان ذلك متوافقًا مع سياسة الجهة ومتطلبات حماية البيانات. النسخة الحالية واجهة أولية؛ قبل الاستخدام الفعلي يفضّل إضافة تسجيل دخول وصلاحيات وصول.
